# 四人 2v2 规则 v1（暂定）

当前实现采用仓库已有的建议规则；团队胜负及聊天保留期的产品确认仍待用户答复。如需调整，须同时更新规则引擎、历史含义、两端文案和测试。

- 恰好四名独立玩家，座位按 A、B、A、B 交替。房主和全员准备后开局；进行中不能换队或离开。每局结束回到等待室并清空准备状态，下局可重新分队。
- 沿用经典 UNO 的发牌、合法出牌、抽牌、方向、跳过、+2、+4 质疑和喊 UNO。功能牌仍按下一个座位生效，不允许指定对手。每人持有独立手牌；队友只见牌数，不能看牌面、交换或代出。
- 任一队员出完手牌，全队立即赢得这场比赛，单轮即为终局。末张 +2 先补罚牌；末张 +4 待接受或质疑裁决后才定胜负。质疑导致出牌者重新持牌时，对局继续。
- 获胜队得分是两名对手终局剩余手牌的牌值总和，记在两位获胜队员名下；败方两人各为零。队友剩余手牌不计分。分数用于结果展示，不累计到经典模式的 500 分门槛。
- `roundWinnerSeat` 是实际出完牌的队员座位；团队由该座位奇偶确定。开局时将每位成员的队伍写入不可变的 `match_players.team_snapshot`，历史胜负不依赖赛后房间座位。

本模式为 UNO 产品组队变体，和 [经典规则](rules-classic-v1.md) 分开。
