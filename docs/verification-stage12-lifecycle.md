# stage12 长期离线与对局中断增量验收（2026-09-24）

## 行为

- 回合截止时间由数据库保存，短断线和刷新读取原截止时间，不重新给时间。带着进行中对局重启 Game 服务后，双方仍读取原截止时间与各自私有视图，过期后可继续裁决。普通回合与开局选色限时 30 秒，+4 回应限时 8 秒；超时继续由服务器裁决。
- V12 起，每位玩家单独记录连续错过本人回合的次数。本人成功提交动作才清零；+4 自动接受不计作漏回合。第三次漏回合后，事务内把对局置为 `INTERRUPTED`，取消倒计时，写入中断事件与原因，房间回到待准备状态，2v2 的语音房间进入删除队列。已提交的正常胜利不会被改为中断。
- 经典局单轮结束后等待 120 秒；无人点击“开始下一轮”时，服务器自动开始下一轮。V12 迁移为升级前停留在 `ROUND_OVER` 的进行中对局补上轮间截止时间。进行中的房间在接受动作后续期，避免长局尚在进行但房间过期。
- `GET /api/matches/{id}/state`、WebSocket `MATCH_SNAPSHOT`、开始和动作回执公开 `status`（`PLAYING`、`ENDED`、`INTERRUPTED`），不公开其他人的手牌。中断历史的 `result=INTERRUPTED`、`winnerUserId=null`，不计胜负。Web/Flutter 牌桌显示中断、停止出牌及队友语音，并可返回待准备房间再开一局；账号页历史也区分中断。

- Web `npm test` 80 项及 `npm run build` 通过；Flutter `dart analyze lib test integration_test` 无问题、`flutter test` 23 项、Android 调试 APK 与 iOS 模拟器构建通过。两端测试包含收到中断快照后不能继续出牌。
- 隔离的 `uno-stage17-check` Compose 栈原有数据卷增量升级至 V12。`UNO_E2E_ORIGIN=http://127.0.0.1:8088 npm --prefix web run test:e2e:classic` 以两个真实浏览器账号完成 19 轮、1010 次界面动作的经典局，随后开始第二局并通过刷新恢复、窄屏检查。原测试脚本让客人只摸牌，曾把几乎整副牌积在该席而无法完成；已改为双方按同一出牌策略操作，再跑通过。旧测试局在无人操作后被 V12 记为中断。
- 升级后 `npm --prefix web run test:e2e:voice` 与 `test:e2e:voice-revoke` 再次通过：四人 2v2、队伍音轨隔离、正常终局清理、会话撤销换房和静音保留均未因 `status` 协议增加而回退。

## 仍待验收

- 上述三次漏回合是本地受控测试默认策略，仍需真实玩家确认是否适合目标局长与网络条件。网络切换、跨实例订阅接管、语音与设备联动及长期负载仍未完成。
- 本轮尚无真机飞行模式/重启实测；集成测试关闭了自动超时扫描并在重启后手动触发一次裁决，还需在部署栈验证自动扫描恢复。单实例数据库恢复不等于多节点故障切换。

## 2026-09-24 主动退出增量

- `POST /api/matches/{id}/leave` 仅对局成员可调用。服务器锁住该局，进行中状态转为 `INTERRUPTED`，原因 `PLAYER_LEFT`、截止时间清空，写一次中断事件；房间转回待准备，退出者离房，其余玩家准备状态清零。房主退出时房主转移。2v2 同时排队清理语音房间；所有原参与者都保有 `INTERRUPTED` 战绩，不虚构赢家。重复请求不重复写中断事件。正常完赛后的退出请求不回写战绩。
- Web 与 Flutter 牌桌需二次确认；收到 `PLAYER_LEFT` 的私有快照显示主动退出原因，收到 `REPEATED_TURN_TIMEOUT` 则显示连续漏回合。退出请求完成后两端再核对房间成员资格，避免与已结束对局竞态时误认为已离房。
- PostgreSQL 集成测试覆盖经典局房主退出/继任、对局动作拒绝、超时不重裁、幂等重试、两人中性历史及 2v2 三人留房/语音清理/四人中性历史。真实 HTTP 与双 WebSocket 的推送集成测试覆盖两人都收到 `PLAYER_LEFT`。Web 93 项测试与生产构建、Flutter 33 项测试、`dart analyze lib test integration_test` 通过。
- 全量重跑时发现本机测试容器的数据库时钟比应用时钟慢约 9 分钟，原先语音清理任务的保留期限依赖数据库 `now()`，会在应用侧提前到期。正常结局/中断和会话换代的清理任务现在由应用时钟明确写入下次尝试与保留期限；后端测试也显式用同一时钟建任务。
- 仍需在 Android/iOS 真机验证弱网、退到后台、主动退出时的语音释放；多人同时退出和网络失败后的用户反馈也待观察。
