# stage3 — 后端账号与会话

[返回总索引](../README.md)

- 状态：部分完成（本地技术项已实现，登录渠道最终确认待定）。
- 前置依赖：stage2；登录渠道尚未最终确认，本轮实现可关闭的本地路径，不开放公网注册。
- 目标：提供真实身份体系，为房间、聊天与语音提供可信 userId。

## 任务清单

- [ ] 按已确认渠道实现注册；当前建议邮箱＋密码，并区分展示昵称和固定身份。
- [x] 使用成熟密码哈希实现，处理重复注册、无效输入和不泄露账号存在性的错误反馈。
- [x] 实现登录、当前用户、退出；明确 Web Cookie 和 App 短期/刷新凭证的有效期、轮换与撤销。
- [x] 接入邮箱验证、找回密码和一次性过期令牌；本地邮件测试工具不能当作真实邮件投递。
- [x] 处理刷新重放、退出后凭证失效、密码重置后的旧会话策略。
- [x] 实现登录/注册/找回限流、基础账号禁用能力、日志脱敏。
- [x] 明确网关与业务服务的可信身份传递/校验，拒绝伪造 userId 或认证请求头。
- [x] 更新协议文档与真实功能状态，不一次性开放全部未完成端点。

## 交付与范围

主要修改 backend/identity-service、gateway、数据库迁移和 docs/contracts。Web Cookie 的 CSRF/Origin 等保护与认证一起交付，不能等到最后阶段再补。

## 验收标准

- [x] 两个真实账号能独立注册登录，数据互不混淆；数据库没有明文密码或原始重置令牌。
- [x] 正确/错误/过期/撤销凭证与重复邮箱均有测试。
- [x] 找回凭证只能使用一次，重置后旧凭证按约定失效。
- [x] 不能绕过网关或伪造头部冒充用户；被禁用身份不能新建有效会话。
- [x] 不借助硬编码演示账号或 permitAll 通过端到端检查。

## 本阶段不包含

双端完整账号 UI、房间、好友系统和多种第三方登录。未确认的手机号/微信登录不擅自加入范围。

## 完成记录

2026-09-07已实现identity V3、内部账号认证服务、Web Cookie/CSRF/Origin校验、App刷新链与重放撤销、加密邮件发件箱、SMTP重试、持久化限流和内部禁用事务。完整接口与边界见 [账号与会话说明](../authentication.md)。

默认AUTH_ENABLED/GAME_AUTH_ENABLED=false；显式本地配置才开放后端认证。Mailpit只接收本机开发邮件，不表示外网邮件已验收。Web/Flutter页面仍是占位；game已提供受保护的只读会话接口，其余游戏业务仍拒绝。

后续已补齐identity到game的内网核验协议与专用服务凭证。game逐请求向identity核验会话，无正向缓存，真实三进程测试验证退出、刷新重放、重置密码、禁用和服务中断。细节见 [跨服务身份](../service-authentication.md) 与 [增量验收](../verification-service-auth.md)。
