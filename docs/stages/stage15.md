# stage15 — Flutter 队友开麦

[返回总索引](../README.md)

- 状态：未开始。
- 前置依赖：stage9、stage13；跨端互通验收依赖 stage14。
- 目标：App 队友语音可用，并完成 Web/App 混合队伍的互听验证。

## 任务清单

- [ ] 接入 Flutter 语音 SDK，复用同一准入和代次协议，不使用客户端硬编码媒体权限。
- [ ] 实现 Android/iOS 运行时麦克风申请、拒绝/永久拒绝提示和再次开启路径。
- [ ] 实现加入、静音、开麦、说话状态、错误、退出，确保按钮反映实际媒体状态。
- [ ] 处理耳机/扬声器、蓝牙切换、系统来电或其他音频占用带来的中断。
- [ ] 首版按已确认的前台语音策略处理锁屏与后台，不擅自加入后台持续录音。
- [ ] 页面销毁、退房、账号退出、对局结束时释放麦克风、音频会话和订阅。
- [ ] 处理网络切换、凭证失效和队伍代次更新；语音失败不阻塞文字/对局。
- [ ] 执行 App/App 与 Web/App 真实设备互通测试，记录平台和网络差异。

## 交付与范围

修改 flutter 的语音模块和平台配置，必要时完善后端/协议。开发可与 Web SDK 接入交叉推进，但 stage15 的跨端验收不能在 Web 语音尚未可用时标完成。

## 验收标准

- [ ] 目标 Android/iOS 设备在用户主动授权后可与同队 Web 或 App 玩家互听。
- [ ] 非队友不可收听，退房/结束/撤销后不再接收当前有效频道音频。
- [ ] 权限拒绝、来电、插拔耳机、前后台和网络切换均有可解释行为。
- [ ] 停止/静音状态与真实麦克风采集一致，不残留后台媒体轨道。
- [ ] 自动测试与真机验证都有记录；缺少某目标平台设备则保留待验收，而非声称双平台通过。

## 本阶段不包含

语音录制、语音转文字、后台持续通话、音效变声和视频功能。

## 完成记录

待补设备系统、SDK 版本、网络环境、混合端互听、音频中断和隐私行为证据。
