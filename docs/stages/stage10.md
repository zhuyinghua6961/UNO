## 任务清单

- [x] 固化四人两队、每队两人、交替座位和开始后队伍不可变的约束。
- [x] 将暂定团队获胜与结果计算加入 game-core；最终产品确认仍待答复。
- [x] 明确牌效目标、伙伴手牌是否可见、是否允许交换等规则，见 [团队规则 v1](../rules-team-v1.md)。
- [x] 后端记录对局队伍快照，不能用赛后变更的房间队伍重算历史胜负。
- [x] 两端显示队友/对手、团队状态与团队结算，个人手牌保持独立。
- [x] 再来一局/退回等待时重新准备，允许的新分队只作用于新局。
- [ ] 队伍与对局代次成为聊天/语音后续授权的可信输入，客户端不能修改。

## 交付与范围

修改 game-core、game-service、队伍/结果迁移及两端牌桌；在规则文档中明确这是产品组队模式，不混同经典默认规则。

## 验收标准

- [x] 四个独立账号以 Web/App 混合方式完成 2v2，团队结果在两端一致（Web 浏览器分别与 iOS、Android 模拟器；见验收记录）。
- [ ] 队伍未达到 2+2、成员重复、开局后换队请求均被服务器拒绝。
- [ ] 伙伴胜利、功能牌收尾和方向改变不破坏团队结果计算。
- [ ] 队友身份可见不等于队友手牌可见；报文不自动泄露队友私牌。
- [ ] 经典模式原有测试保持通过，团队规则不能污染经典局。

## 本阶段不包含

队伍匹配、长期战队、队伍排位、文字和开麦。组队基础完成后再启用通信。
