# stage12 — 重连与对局生命周期

[返回总索引](../README.md)

- 状态：进行中（单实例接管、短断线恢复、连续漏回合中断和轮间超时已实现；跨实例与设备故障仍待做）。
- 前置依赖：stage10、stage11。
- 目标：把正常网络下可玩提升为刷新、断线、重试与退房行为可预测的受控测试版本。

## 任务清单

- [ ] 明确回合超时、质疑窗口、短断线保留、长期离线/主动退出、中断和正常完赛状态机。
- [ ] 固化不依赖客户端时钟的计时与恢复；连接抖动不能重置回合倒计时获得额外时间。
- [ ] 实现刷新/重新登录后的身份与席位恢复、完整视图替换和消息序号补偿。
- [ ] 实现同账号单局有效操作连接的接管规则，旧连接立即失去写权限。
- [ ] 处理结束前后重试、切后台、网络切换、重复订阅和空房回收。
- [ ] 服务重启后至少能识别遗留局并标记系统中断；是否跨进程续局另行明确，不能默认承诺。
- [ ] 正常完赛事务只执行一次；中断不计正常胜率，产生可供历史查询的准确记录。
- [ ] 输出成员/代次/对局结束通知，为 stage13 撤销语音资格提供可靠触发。

## 交付与范围

修改游戏调度、房间生命周期、会话联动、两端恢复逻辑与必要的数据迁移。计时数值是产品配置，不宣称它们是官方 UNO 规则。

## 验收标准

- [ ] 刷新、飞行模式后恢复、临时网络切换不会重复摸牌或出现两套手牌。
- [ ] 同账号双端抢占操作权符合约定，被接管连接不能继续发有效动作。
- [ ] 断线/退房发生在 UNO、+4 质疑、结算窗口时仍能明确结束或恢复。
- [ ] 服务器重启不会把中断局当成正常胜利；不丢失已经提交的完赛记录。
- [ ] 对局结束清理计时器和订阅，持续新建/结束房间不不断累积资源。

## 本阶段不包含

机器人接管、跨区域容灾、分布式房间迁移和实际媒体撤销。语音加入后继续复用并扩展这些生命周期测试。
