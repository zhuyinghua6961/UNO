## 验收标准

- [x] 相同初始状态、随机输入和动作序列得到相同结果。
- [x] 合法/非法动作、两人局、功能牌收尾、UNO 窗口、+4 质疑均有明确用例。
- [x] 对局过程中牌不重复、不丢失，总量守恒；规则拒绝不会部分修改状态。
- [x] 私有视图只能看到本人手牌，其他玩家仅公开信息；质疑证据按规则定向处理。
- [x] 测试覆盖一次正常完整对局以及关键罚牌链路。
