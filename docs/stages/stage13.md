# stage13 — 队友语音后端

[返回总索引](../README.md)

- 状态：进行中；会话吊销、媒体代次轮换与旧令牌隔离已在本机验收，跨网络和容量仍待验收。
- 前置依赖：stage3、stage10、stage12。
- 目标：让只有当前对局的合法队友能取得语音资格，并在离开/结束后失去资格。

## 任务清单

- [x] 接入 LiveKit 服务端凭证与管理调用；秘密留在服务器，不交给浏览器或 App。
- [x] 实现语音准入端点，从真实会话和 matchId 推导队伍、对局媒体代次和媒体房间。
- [x] 只允许进行中的有效 2v2；两队使用不同媒体房间，不靠前端静音实现隔离。
- [x] 签发绑定身份、指定房间、仅麦克风发布的短期凭证，禁止视频/屏幕/任意建房和管理权限。
- [x] 对局结束删除房间；已连接会话登出、过期、账号禁用时轮换房间并断开旧连接。进行中房间不允许离队或换队。
- [x] 新代次供有效队员重新申请，旧代次重复删除直到旧令牌到期；本机真实媒体测试验证旧令牌重放不能听到新代次队友。
- [x] 对令牌获取限流，屏蔽凭证日志；处理 LiveKit 不可达、终局房间删除失败和重试幂等，并在短令牌过期前重复清理终局房间。
- [x] 准备可实际连通的测试媒体环境，说明本机回环配置的适用范围。

## 交付与范围

修改 game-service 的语音准入/生命周期模块、deploy 的开发媒体配置与协议。CommunicationPolicy 单元测试保留，但必须新增真实会话/成员与媒体管理集成测试。

## 验收标准

- [x] 请求自带伪造 teamId/userId/roomName 不能改变服务端选择的目标。
- [x] 对手、非成员、经典局、已结束对局不能获取不属于自己的语音资格。
- [x] 合法测试客户端只能进入对应队伍房间并发布允许的音频类型（本机 Chromium 假麦克风与 LiveKit 实连）。
- [x] 会话登出与终局后已有连接被处理，旧令牌重放不能听到新代次有效队员的音频；账号禁用由相同会话检查路径覆盖，尚未做公网压测。
- [x] 媒体系统故障时出牌与文字仍可继续，失败有清楚错误而非卡死对局。

## 本阶段不包含

Web/App 正式开麦界面、录音、视频会议、全房间语音和生产公网部署。
