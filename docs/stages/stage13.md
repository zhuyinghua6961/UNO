# stage13 — 队友语音后端

[返回总索引](../README.md)

- 状态：未开始。
- 前置依赖：stage3、stage10、stage12。
- 目标：让只有当前对局的合法队友能取得语音资格，并在离开/结束后失去资格。

## 任务清单

- [ ] 接入 LiveKit 服务端凭证与管理调用；秘密留在服务器，不交给浏览器或 App。
- [ ] 实现语音准入端点，从真实会话和 matchId 推导队伍、成员代次和媒体房间。
- [ ] 只允许进行中的有效 2v2；两队使用不同媒体房间，不靠前端静音实现隔离。
- [ ] 签发绑定身份、指定房间、仅麦克风发布的短期凭证，禁止视频/屏幕/任意建房和管理权限。
- [ ] 接入离队、封禁、会话撤销、对局结束通知，主动移除媒体成员并清理相关会话。
- [ ] 实现成员代次变更与有效队员迁移，处理旧令牌过期前重放；不能只依赖令牌有效期或一次踢人。
- [ ] 对令牌获取限流，屏蔽凭证日志；处理 LiveKit 不可达、移除失败和重试幂等。
- [ ] 准备可实际连通的测试媒体环境，说明本机回环配置的适用范围。

## 交付与范围

修改 game-service 的语音准入/生命周期模块、deploy 的开发媒体配置与协议。CommunicationPolicy 单元测试保留，但必须新增真实会话/成员与媒体管理集成测试。

## 验收标准

- [ ] 请求自带伪造 teamId/userId/roomName 不能改变服务端选择的目标。
- [ ] 对手、非成员、经典局、已结束对局不能获取不属于自己的语音资格。
- [ ] 合法测试客户端只能进入对应队伍房间并发布允许的音频类型。
- [ ] 退出/封禁/结束后已有连接被处理，旧令牌重放不能听到新代次有效队员的音频。
- [ ] 媒体系统故障时出牌与文字仍可继续，失败有清楚错误而非卡死对局。

## 本阶段不包含

Web/App 正式开麦界面、录音、视频会议、全房间语音和生产公网部署。

## 完成记录

待补受限凭证检查、准入攻击测试、撤销/重放测试、媒体环境与异常回退证据。
