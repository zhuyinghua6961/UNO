# stage8 — Web 经典对局

[返回总索引](../README.md)

- 状态：已完成（本地验收）。
- 前置依赖：stage7。
- 目标：用 Vue 完成第一个真实可玩的经典局闭环。

## 任务清单

- [x] 将牌桌预览替换为真实房间和对局状态，明确连接中、等待、对局、结算和错误状态。
- [x] 展示本人手牌、他人牌数、当前颜色/方向、当前玩家和服务器截止时间。
- [x] 实现选牌、出牌、摸牌、摸牌后放弃、万能选色，操作结果以服务端确认更新。
- [x] 接入 UNO 宣告/抓漏喊、+4 接受/质疑等窗口，不漏掉规则引擎的交互分支。
- [x] 处理重复点击、命令等待/拒绝与状态补同步，不让动画成为业务真相。
- [x] 完成胜负页、返回房间和再来一局；新局不沿用旧局手牌或请求。
- [x] 接入适量音效、静音设置、卡牌选择反馈和移动浏览器布局。
- [x] 去掉已实现功能的演示标签；未实现聊天/语音继续标记禁用。

## 交付与范围

修改 web 的房间、牌桌、结算、实时连接模块与端到端测试；必要的协议变化回写 docs/contracts，不在前端创建另一套权威规则。

## 验收标准

- [x] 至少两个独立真实账号可在浏览器完成经典局并开始下一局。
- [x] UNO/+4/选色/摸牌后动作可从界面完成，不需要手工调用接口。
- [x] 点击连发、服务器拒绝、延迟到达事件不会导致手牌与服务器分叉。
- [x] 桌面与窄屏可操作，手牌不被聊天占位遮挡，颜色信息不只靠颜色表达。
- [x] 页面切换和对局结束清理事件监听与旧连接，不重复播放/重复处理事件。

## 本阶段不包含

Flutter 实战、2v2、真实聊天、语音和完整弱网体验；正常网络可玩不代表已具备生产可靠性。
