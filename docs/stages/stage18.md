# stage18 — 综合验收与发布

[返回总索引](../README.md)

- 状态：进行中（0.3.5 本地包的跨端验收矩阵已建立；真机、跨网媒体、签名和发布门槛未通过）。
- 前置依赖：stage17，以及所有本次版本声明具备的功能阶段已验收。
- 目标：把“能运行”变成可交付的内测版本，明确已通过、未支持和剩余风险。

## 任务清单

- [x] 制定初版版本验收矩阵：Web/Android/iOS、经典/2v2、账号、文字、语音、重连和个人记录；未通过项继续补验。
- [ ] 覆盖冒充用户、伪造队伍、跨队消息/历史、偷看手牌、令牌重放、会话撤销和敏感日志等安全回归。
- [ ] 执行弱网、网络切换、重复动作、服务重启、麦克风拒绝/中断、对局结束清理等故障测试。
- [ ] 与用户确认并发和延迟目标后压测，记录环境、数据规模、CPU/内存/连接/媒体容量，不虚构承载上限。
- [ ] 检查素材许可、正式名称/包名、隐私与麦克风说明、文字举报/处理和必要的发布要求。
- [ ] 在目标真机上验证安装、登录、升级与卸载；使用用户授权的正式签名，区分 debug/unsigned/release。
- [ ] 从已验证的源码版本构建 Web、JAR、镜像和目标平台包，生成 manifest、SHA-256、变更说明与已知问题。
- [ ] 将实际交付制品归档到 release，按授权上传私有 Release/制品库；确认回滚和内测反馈入口。
- [ ] 只在证据齐备后标阶段完成；部分平台缺签名/缺验证时交付说明必须明确限制。

## 交付与范围

输出版本验收报告、实际安装/部署制品、版本与协议兼容信息、运维/回滚说明。release 不含秘密、数据库用户数据、个人签名私钥或未经批准的录音/聊天原文。

## 验收标准

- [ ] 版本声明的每个功能有真实端到端证据，不能将开发骨架或 SDK 模拟测试当作完整交付。
- [ ] 明确的目标平台与网络场景通过测试；跨队泄露、无法撤销等关键安全问题不能带病通过。
- [ ] 功能/性能目标、未支持范围、已知问题和发布批准状态均有记录。
- [ ] 安装包、镜像、静态资源、数据库迁移和源码版本对应，校验和可以复验。
- [ ] 从文档能完成安装/部署与回退；没有声称未实际生成或未签名的 APK/IPA 已可分发。
- [ ] 私有仓库、分支、提交、标签与远程发布操作仅在明确授权范围内进行。

## 本阶段不包含

排位、商城、付费、语音录制和未承诺平台。这些应作为新版本阶段另行评估，不塞进本次验收尾声。
