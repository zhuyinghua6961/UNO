# stage14 — Web 队友开麦

[返回总索引](../README.md)

- 状态：未开始。
- 前置依赖：stage8、stage13。
- 目标：浏览器队友能在主动授权后互听，且不影响牌桌操作。

## 任务清单

- [ ] 接入 LiveKit Web SDK，与真实语音准入端点交互，不把 API secret 打进前端。
- [ ] 只有用户主动点击加入语音后申请麦克风，不在登录/进房时自动采集。
- [ ] 实现连接中、已加入、静音、开麦、退出、被撤销和失败状态。
- [ ] 显示队友说话状态和设备问题，处理权限拒绝、无麦克风与播放限制。
- [ ] 页面离开、对局结束、账号退出时停止媒体轨道、取消监听并离开媒体房间。
- [ ] 处理令牌/代次更新、媒体重连和后端撤销，不能只改变 UI 图标。
- [ ] 区分本机开发与 HTTPS 测试环境；预设不支持的浏览器行为要有说明。
- [ ] 增加不采集真实音频的组件测试与真实麦克风人工连通验收。

## 交付与范围

修改 web 的通信/语音模块和权限提示，使用 stage13 的受限凭证。两名浏览器玩家的声音连通是真实验收项，按钮变绿或 SDK 返回连接成功不是全部证据。

## 验收标准

- [ ] 两名同队 Web 玩家实际可以互听；另一队不能进入该频道。
- [ ] 未点击加入前没有采集轨道；拒绝权限后仍能正常出牌和发文字。
- [ ] 静音/退出真实停止对应音频传输，关闭页面后麦克风不继续占用。
- [ ] 对局结束、会话撤销、旧令牌和媒体重连行为与后端规则一致。
- [ ] 测试记录包含浏览器、网络、HTTPS 条件、实际听感与未支持场景。

## 本阶段不包含

App 开麦、后台录音、音频保存、直播和全房间语音。

## 完成记录

待补权限行为、双人互听、队伍隔离、静音/退出以及撤销后的真实音频验证。
