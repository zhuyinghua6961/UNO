## 交付与范围

修改 web/src 的账号/会话模块、flutter/lib/features/auth 和网络配置；同步两端错误文案与协议类型。此阶段只开放已真实实现的账号能力。

## 验收标准

- [ ] 同一个账号可以分别在 Web/App 登录，稳定对应同一 userId。
- [ ] 刷新网页、重启 App、凭证过期和退出登录均符合约定。
- [ ] 错误密码、服务不可达、邮件未验证等状态有清晰提示，不模拟成功。
- [ ] 登录失败不进入受保护页面，退出后不能继续使用已撤销会话。
- [ ] 两端注册到退出的流程有自动测试；移动端安全存储验证记录可追溯。

## 本阶段不包含

创建真实房间、对局和完整个人战绩。跨端登录不代表对局已经互通。
