# stage11 队伍文字增量验收

日期：2026-09-24。规则：仅四人 2v2 房间有队伍频道，客户端只能请求 `TEAM` 范围，实际 A/B 由服务器根据当前席位决定。

- V8 给房间成员保存当前队伍频道的加入序号。换队或重新加入时以目标队伍现有末序号作为下限；团队历史同时受当前成员资格、加入时间与队伍序号约束。发送和换队均锁房间行，历史查询使用一致的事务快照。`ChatServiceIT` 验证 A/B 消息隔离、伪造频道拒绝、非成员拒绝、跨频道消息 ID 冲突、A→B→A 后旧队历史不可回看、经典房间无队伍频道。定向 Maven PostgreSQL 集成测试通过。
- Web 76 项测试和生产构建通过；Flutter 18 项测试和 `dart analyze lib test` 通过。两端等待室与牌桌均可切换房间/队伍文字，失败时保留重试消息 ID，按频道独立恢复游标。以上是自动测试与构建，尚非真实设备 UI 验收。
- 保留原隔离 Compose 数据卷并从 V7 增量迁移到 V8，更新 Game/Web 镜像。`SMOKE_TEAM_MATCH=true node tools/smoke-auth-chat.mjs` 经 Gateway 使用四个真实注册验证账号：A 消息只在两个 A 账号历史出现，B 消息只在两个 B 账号历史出现；请求 `TEAM_A` 伪造频道返回 400。随后同一房间正常开局、完赛并核对团队战绩及房间重置。脚本不打印密码或令牌。

尚未验证 Web/Android/iOS 设备上频道切换与输入体验。当前靠 2 秒 HTTP 游标补取，尚无聊天 WebSocket 事件、未读提醒、禁言/举报与正式保存/删除政策；30 天保存期仍为暂定。
